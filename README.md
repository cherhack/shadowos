# ShadowOS 1.0 beta

Неофициальная персональная игровая сборка на базе CachyOS для следующей машины:

- Ryzen 5 7500F;
- NVIDIA RTX 3070 8 ГБ;
- 16 ГБ ОЗУ;
- отдельный NVMe 256 ГБ;
- Windows остаётся на другом диске.

Это не новый дистрибутив «с нуля» и не официальный продукт CachyOS. Сборка
сохраняет репозитории и установщик CachyOS, добавляя выбранную оболочку,
настройки и безопасные сценарии автоматизации.

## Что входит

- Hyprland и оригинальный DarkShadowShell 3.16;
- графитово-серая палитра, монохромные обои, автоскрываемый нижний Dock,
  компактная верхняя панель и умеренные эффекты;
- Steam, Wine, Lutris, GameMode, MangoHud и ProtonUp-Qt (если пакет доступен);
- автоматическое упрощение эффектов DarkShadowShell на время работы GameMode;
- Bottles из Flathub, устанавливаемый Calamares или при первом запуске;
- двойной клик по EXE/MSI с отдельным Wine-префиксом и подтверждением хеша;
- драйверы NVIDIA/Vulkan, выбираемые штатным `chwd` CachyOS;
- ZRAM до 8 ГБ для системы с 16 ГБ памяти;
- Btrfs и постоянный снимок чистой установки через CachyOS Snapper support;
- стандартный GRUB, таймер 5 секунд и минимальная тёмная тема со скруглённым меню;
- Shadow AI: гибридный OpenAI-совместимый клиент с белым списком действий,
  резервными копиями и polkit-подтверждением;
- дополнительная защита диска Windows: найденный диск переводится в режим
  «только чтение» на время live-сеанса.

## Важные ограничения

1. **Установка сотрёт выбранный целевой диск.** Перед подтверждением трижды
   сверь модель, серийный номер и объём NVMe. Надёжнее всего временно отключить
   диск Windows и иметь свежую резервную копию.
2. Целевая установка онлайн: нужен интернет для скачивания актуальных пакетов.
3. Secure Boot для первого запуска лучше отключить в UEFI.
4. Wine/Proton не запускают абсолютно все EXE. Игры с некоторыми античитами,
   DRM и драйверами уровня ядра Windows не заработают.
5. Shadow AI не содержит API-ключа. После установки нажми `Super+Space`, введи
   `/setup` и укажи свой OpenAI-совместимый HTTPS API.
6. Это beta-сборка. QEMU проверяет загрузку, но окончательная проверка RTX 3070,
   мониторов, звука и сна возможна только на целевом компьютере.

## Установка

1. Скачай **все** файлы `*.iso.part-*`, `SHA256SUMS` и скрипт объединения из
   одного GitHub Release.
2. В Windows запусти PowerShell в папке загрузок:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\join-shadowos.ps1
   ```

   Скрипт соберёт ISO и автоматически проверит SHA-256.
3. Запиши ISO через Rufus в DD-режиме или скопируй его на Ventoy.
4. Загрузи флешку в UEFI-режиме, подключись к интернету и открой
   **Install ShadowOS**.
5. Установщик покажет диски и защитит обнаруженный диск Windows от записи.
6. Выбери отдельный NVMe 256 ГБ, GPT, Btrfs и GRUB. Для этого сценария не нужен
   отдельный раздел `/home`: Calamares создаёт Btrfs-подтома.
7. После установки проверь, что UEFI загружает GRUB с NVMe ShadowOS. Windows
   должна появиться через `os-prober`; если нет, её всегда можно выбрать из
   штатного меню загрузки материнской платы.

## Shadow AI

`Super+Space` открывает помощника. Локальные команды работают даже без API:

```text
/doctor
/gaming on
/gaming off
/lite on
/theme violet
/dock on
/undo
```

Для игр Steam, которые сами не запрашивают GameMode, укажи один раз в параметрах
запуска игры: `gamemoderun %command%`. EXE, запущенные встроенным обработчиком,
используют GameMode автоматически, кроме установщиков и обновлений.

Обычный текст отправляется выбранной модели. Модель только предлагает JSON-план;
локальный клиент отклоняет неизвестные действия и никогда не исполняет выданный
моделью shell-код.
